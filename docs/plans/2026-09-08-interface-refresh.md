# 旧版公开页与新版界面的选择性融合

## 最终范围

按用户最新选择，只保留新版公开页顶栏、反馈窗口、暗色配色及整个新版管理后台。公开页以当前提交 d013172 为底稿，其余结构、浅色样式和业务交互保持旧版。

- 顶栏：保留双行品牌、导航、反馈／登录及通知、主题工具；宽度对齐旧版主体，适当收敛圆角和间距。
- 反馈：保留新版窗口层级、输入样式、提交中状态、失败后保留内容、键盘与遮罩关闭。
- 暗色：采用新版蓝灰底色、青色强调及状态颜色，保留旧版卡片布局和着色方式。
- 后台：保留新版全部页面和交互，将基础样式独立到管理目录，避免受旧公开页样式影响。

## 保持旧版的内容

搜索与筛选、分类、统计摘要、卡片、分组、价格、时间条、分页、模型详情、运行通知及自动弹出逻辑、轮询和数据读取均沿用旧版。旧版清空按钮只清分类条件。公开页不保留上一轮添加的页面引导、概况统计、排序、紧凑列表、已选条件栏、地址恢复、手机筛选折叠和通知横幅。

公开页两份原有样式文件完整还原；新增样式只包含顶栏、反馈窗口及暗色颜色变量。后端运行代码和接口保持不变，不增加生产依赖。

## 验证要求

1. 逐段核对公开页与旧版源码，确认差异限于获准区域。
2. 核对后台脚本与页面仍为上一轮版本，基础样式迁移后呈现一致。
3. 使用隔离的本地演示数据验证桌面、手机、浅色和暗色，以及反馈提交、失败重试和关闭。
4. 验证旧版搜索、筛选、卡片、详情、分页和运行通知继续工作。
5. 运行完整项目检查与差异检查，确认无后端或敏感信息改动。
