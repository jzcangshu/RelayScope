# Phase 3 and Phase 4 Completion Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Complete the remaining management workflows and release infrastructure while preserving RelayPulse's single-process, SQLite-only, low-resource architecture.

**Architecture:** Extend existing store methods and HTTP routes with narrow contracts. Site deletion is a recoverable soft delete represented by `deleted_at`; deleted sites stop scheduling, disappear from public and admin lists, and retain historical rows for retention cleanup. Runtime tuning remains explicit configuration passed into collector, scheduler, and HTTP server. The frontend stays embedded static JavaScript with no runtime dependency.

**Tech Stack:** Go 1.26, modernc SQLite, embedded HTML/CSS/JavaScript, GitHub Actions, Docker.
